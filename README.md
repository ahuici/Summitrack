# SUMMITRACK AIMAR HUICI #

Summitrack de Aimar Huici, TFG Desarrollo de Aplicaciones Multiplataforma

## Instalacion

#### Para poder instalar el programa necesitaras tener instalado lo siguiente:
* MySQL Workbench

#### Como configurar el programa para ejecutarlo:
 1. Mirar en que puerto tienes MySQL Workbench funcionando, recuerdalo.
 2. En src/main/resources/application.properties en la linea 7 (spring.datasource.url=jdbc:mysql://localhost:3308/summitrack) cambia el numero por tu puerto, por defecto sera el 3308.
 3. Entra en MySQL Workbench y haz click derecho en Schemas, create Schema y escribe "summitrack". Crea el esquema
 4. Ya tienes el programa configurado.
